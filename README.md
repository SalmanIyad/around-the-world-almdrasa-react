# 🌍 Around The World  

**Around The World** is a React-based web project that showcases information about different countries worldwide. The application fetches real-time data from the **REST Countries API** and presents it in a visually appealing and user-friendly interface. It offers various features to enhance navigation and interactivity, making it a great tool for exploring countries effortlessly.  

This project was developed as part of the **React Projects Course** on **[Almdrasa.com](https://almdrasa.com/)**.  

## 🚀 Live Demo  
[🔗 Around The World](https://around-the-world-almdrasa-react.vercel.app/)  

## ✨ Features  
- 📌 **Display Country Cards** – View essential details about each country.  
- 🌍 **Filter by Region** – Easily browse countries by continent.  
- 🔍 **Search Functionality** – Quickly find a country by name.  
- 🌗 **Dark & Light Mode** – Switch between themes for a better viewing experience.  
- 🛠️ **Detailed Country View** – Click on a country card to access in-depth information.  
- ⚡ **Fast & Responsive** – Optimized for smooth performance across all devices.  

## 🛠 Technologies Used  
- ⚛️ **React + Vite** – For fast and efficient UI development.  
- 🎨 **Tailwind CSS & MUI** – For modern and responsive styling.  
- 🌐 **RESTful API** – To fetch real-time country data.  
- 🏗 **Modular & Maintainable Code** – Ensuring clean and scalable architecture.  

## 🌐 API Used  
The project utilizes the **[REST Countries API](https://restcountries.com/)** to fetch detailed information about countries, including population, capital, region, currency, and more.
